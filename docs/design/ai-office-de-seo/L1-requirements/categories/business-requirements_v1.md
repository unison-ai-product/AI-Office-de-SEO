# AI Office de SEO 業務要求

## 責務

利用者、運営者、コンサルタントが、どの業務成果をどの責任分担で達成するかを定義する。

含むもの:

- 初期導入、日常運用、記事制作、リライト、承認、公開、効果確認
- Owner / Admin / Editor / Viewer / 開発管理者の業務責任
- レコメンド主導運用と手動探索の位置づけ
- 例外、差し戻し、保留、見送り、緊急停止
- 完了条件、業務SLA、人的エスカレーション

含まないもの:

- 優先順位の計算式
- DB項目
- API方式
- 画面レイアウト

既存ソース: `ai-office-de-seo-user-journey-requirements_v3.7.md`、`ai-office-de-seo-product-requirements_v3.7.md`、L0ビジネス要求。

## 要求

### REQ-BUS-01 レコメンド主導運用

記事制作とリライトの既定業務導線は、優先順位付きレコメンドの確認、採否判断、実行、効果確認とする。自由なキーワード・URL指定は補助導線として残し、ユーザーへ同じ戦略情報を再入力させない。

### REQ-BUS-02 正式な推薦結果

業務上の推薦結果は新規作成、リライト、統合・canonical、内部リンク、CTA更新、鮮度更新、保護、監視、見送りを含む。記事本数の増加だけを成果とせず、好調記事の保護と不要施策の見送りを正式な結果として扱う。

### REQ-BUS-03 推薦から実行への引継ぎ

採用された推薦は、対象、目的、根拠、期待改善、変更範囲、品質条件、予算をTicketまたはEdit Planへ引き継ぐ。実行前に権限、承認、予算、好調記事保護、重複、公開条件を再検証する。

### REQ-BUS-04 初期導入

初期導入では契約組織、対象Site、GSC、WordPress、代表記事、サイト方針、禁止表現、CVポイント、承認者、予算を登録し、接続・権限・計測・投稿経路を検証する。未完了項目は明示し、安全に実行できない機能を有効化しない。

### REQ-BUS-05 記事制作・リライト

新規記事は未充足の検索意図、問い、サイト内の役割、既存記事との重複を確認して制作する。リライトはQuery Drift、実績、記事サマリーの不足・鮮度・意図ずれ、競合差分、施策履歴から変更範囲を最小化する。

### REQ-BUS-06 人と自動化の責任分担

システムは調査、候補生成、下書き、検証、投稿準備、公開、効果計測までをイベント駆動で実行できる。新規Siteは最初の公開成功15記事について公開前の人間承認を必須とする。15記事到達後、権限者が自動投稿の同意書へチェックし、対象範囲、予算、品質条件、停止条件を設定した場合に自動投稿モードを解放する。この同意・設定記録を自動投稿に対する人の確認事実として扱い、個別記事承認を不要にできる。公開内容の最終責任は公開者に帰属し、サービス提供者は契約・法令で強制される範囲を除きSEO成果および公開内容の正確性・適法性を保証しない。責任条項の対外文言は法務レビューを受ける。

### REQ-BUS-07 例外と見送り

入力不足、根拠不足、古いデータ、予算不足、権限不足、品質不合格、外部障害、好調記事への悪影響がある場合は、自動実行せず保留、差し戻し、監視または見送りとする。自動投稿モードもこの停止条件を解除しない。理由と解除条件をユーザーへ提示する。

### REQ-BUS-08 効果確認と学習

実行した施策は対象、種別、実施日、変更範囲、費用、事前指標と事後指標を施策台帳へ記録する。採用、編集、却下、保留理由と実施後効果を、同じ不適切な推薦の反復抑制と優先順位較正へ使用する。

### REQ-BUS-09 コンサル・完全委託

自社コンサルタントまたは運用担当者は、権限付与された組織・Site・操作範囲内で初期設定、戦略確認、推薦採否、実行管理、報告を行う。契約範囲外の操作、顧客間データ共有、公開者責任の代替を行わない。代理店運用、OEM、ホワイトラベルは対象外とする。

### REQ-BUS-10 成果非保証

順位、流入、CV、売上、工数削減は参考予測または検証対象として扱い、保証しない。対外表示する数値は測定条件、期間、対象、根拠、免責を持つ。

## 受入条件

- [ ] AC-BUS-01: 初期画面から推薦の確認、採否、実行、効果確認へ遷移できる。
- [ ] AC-BUS-02: 新規作成以外に統合、保護、監視、見送りが推薦結果になる。
- [ ] AC-BUS-03: 採用した推薦の根拠と条件がTicketへ欠落なく引き継がれる。
- [ ] AC-BUS-04: 初期導入の未完了項目と利用不能機能が判別できる。
- [ ] AC-BUS-05: リライトで無条件の全文再生成が既定にならない。
- [ ] AC-BUS-06: 新規Siteの公開成功15記事までは確認者を記録し、到達後も同意書チェックと権限者の設定なしに自動投稿が有効にならない。
- [ ] AC-BUS-07: 実行不能時に理由、解除条件、次の操作が提示される。
- [ ] AC-BUS-08: 推薦の採否と実施後効果が施策台帳へ接続される。
- [ ] AC-BUS-09: コンサル・代行者が未許可の顧客・Siteを操作できない。
- [ ] AC-BUS-10: 予測表示と対外訴求に成果保証表現が含まれない。
